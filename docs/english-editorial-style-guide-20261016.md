# Slotfolio English editorial localisation guide (v1)

English copy is **adapted for readers**, not produced as a literal Russian-to-English substitution. Write for an international audience using consistent UK English spelling, with clear regional qualifiers where a law or help service is country-specific.

## Voice
- Useful, measured, informed and readable. Explain rules rather than sell excitement.
- Prefer concise, natural constructions: “How wins are formed”, “Check the game's paytable”, “Which RTP setting is in use?”
- Do not translate Russian idioms literally. Rewrite the sentence around the information a reader needs.
- Separate **documented mechanics** from editorial explanations. Avoid claims about fairness, trustworthiness, speed of withdrawal, operator availability or profitability without confirmed sources.
- Use direct language for risk: “You can lose the money you stake.” Do not suggest a result is “due”, or that RTP predicts short-term outcomes.
- Keep game and provider names as their official titles. Do not translate brands, nominal bonus labels or game-specific feature names without a publisher source.
- Use quotation marks and punctuation naturally; preserve figures exactly and use English number formatting only when units and meaning remain unchanged.
- Retain clear 18+ and safer-gambling information and mark regional help as region-specific.

## Terminology decisions

| Original idea | Preferred English | Avoid |
|---|---|---|
| RTP / возврат игроку | return to player (RTP) / theoretical RTP | “refund rate”, “guaranteed return” |
| волатильность | volatility | “winning chance”, “risk score” |
| максимальный выигрыш | maximum win, e.g. 5,000× stake when confirmed | “profit”, “guaranteed payout” |
| линии | paylines | “payout roads” |
| каскады | cascades / cascading reels, according to publisher | “chain wins” as a universal mechanic |
| кластерные выплаты | cluster pays / adjacent-symbol wins | “lines” |
| способы выплаты | ways to win / ways | fixed paylines unless confirmed |
| фриспины | free spins | “free money” |
| дикий символ | wild symbol | “joker” in generic descriptions |
| скаттер | scatter symbol | unverified bonus guarantee |
| отыгрыш бонуса | wagering requirements | “wager” as a rate |
| источник разработчика | publisher's rules / official game materials | unqualified casino claims |
| ответственный гемблинг | safer gambling | promises of “safe gambling” |

Use *casino* only where the content actually refers to an operator; not interchangeably with publisher. Use *paytable* for the game's displayed rule chart. Keep UK spelling (catalogue, licence, organised). The English edition is not UK-only: country-specific regulatory references, self-exclusion schemes and gambling rules require a stated territory.

## Editorial QA checklist for every translated page
1. Compare every factual claim, figure, exception, link and disclaimer to the latest Russian page and its primary supporting source. Do not invent missing values.
2. Rewrite headings, examples and transitions so they sound natural in English; avoid sentence-for-sentence calques. Check grammar, rhythm, scannability and reader intent.
3. Audit terms against the glossary and the publisher's official name for any game-specific feature.
4. Check all buttons, links, placeholders, alt text, metadata, breadcrumbs, keyboard labels and mobile layouts; mark Russian-only destinations as such.
5. Verify the correct route, self-canonical, hreflang only where both full translations exist, and `lang=en`.
6. Preserve the strict original image/artwork check and all CI gates. Do not publish incomplete mixed-language game dossiers as if translated.
7. Both locales remain **noindex** until a separate editorial, legal/affiliate and technical approval for public indexing.

## Translation coverage
The seven-page /en pilot is complete only once its exact-head CI and Cloudflare deployment succeed. **Game dossiers and catalogue remain untranslated**. The next independently reviewed delivery should translate catalogue interface controls first, then full dossiers in reviewable batches, then catalog-only records, without changing the published 100+900 selection.
