No document-level horizontal overflow was found in the baseline representative route matrix. Table overflow is intentionally confined to its own scroll region. Body and principal muted/accent text retain distinguishable contrast on the paper background; this audit does not claim a complete WCAG certification. The main readability failures are size and available width, not a need for a new visual palette. Editorial article layouts, provider/mechanics indices, collections index and footer remain recognizably consistent with the atlas concept.

## CSS evidence

`layout.tsx` imports five global layers: `globals.css`, `v127-overrides.css`, `catalog-card-polish.css`, `fact-layout-polish.css`, `typography-readability.css`, alongside component/route modules. `globals.css` has 4,771 lines; a simple selector inventory counts 1,163 rule blocks. Exact repeated selector counts include `.catalog-search` 13, `.catalog-game` 12, `.results-toolbar` 8 and `.filter-panel` 8. Counts include media queries and are not proof that every repetition is redundant.

Concrete conflicts: `globals.css:4617` assigns the old inner passport grid; the catalog record module originally changed the outer grid but did not reset the inner display. `fact-layout-polish.css` repairs only `.facts-wide`. `catalog-card-polish.css` declares 10–13px text subsequently superseded by the readability layer. Generic `.slot-tag-list` right alignment/max-width constraints survive unless specifically reset. Palette values are declared at the start and overridden again near the end of `globals.css`. Preserve the computed result while consolidating one component at a time in future work.
